新建任务向导

对应 C# 的 WizardWindow：读取一份 profile json，预览项目设置， 选择输入文件，然后为每个输入文件新建一个任务。 每个任务都会带上向导推导出的 input_script / working_path_prefix / output_path_prefix。

← 返回任务列表

1. 选择项目文件

把 profile json 拖到这里也可以。

浏览器拿不到文件的真实路径，而 profile 里的相对路径、生成的 vpy 与输出目录都要 以它为基准，所以需要手工填一次。留空时按当前工作目录解析（与 POST /api/v1/tasks 的 base_dir 语义一致）。

向导会为每个输入文件生成一份脚本：把 #OKE:INPUTFILE 的取值换成 该输入文件，把 #OKE:DEBUG 置为 None，把 #OKE:PROJECTDIR 换成上面的目录。所以这里要填脚本的内容， 不是路径 —— 浏览器读不到同级文件。

项目设置预览（只读）

2. 选择输入文件

列表来自 profile 的 InputFiles。选中的每一个文件都会新建一个任务， 各自生成自己的 vpy 与输出路径。

3. 每个源文件的独立配置

对应 EpisodeConfig。C# 的向导会读与源文件同名的小 json （<输入文件>.json），浏览器读不到同级文件，所以在这里填。 留空则每个任务的 Config 为空。

也接受每行 begin end 的简写。切片会先排序再合并，区间重叠会被拒绝。
